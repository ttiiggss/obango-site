# Oliver White Personal Website

This is Oliver White's personal website—a modern, minimal showcase of multidisciplinary expertise spanning technical infrastructure, creative design, and strategic leadership.

## Features

- **Modern Dark Theme** with subtle gradients and smooth reveal animations
- **Fully Responsive** design that works beautifully on all devices
- **Semantic HTML** with accessible markup and ARIA labels
- **Zero Build Tools** required—just open `index.html` in a browser
- **Intersection Observer** animations for elegant content reveals

## Quick Start

1. **View Locally**: Simply open `index.html` in your web browser
2. **Customize Content**: Edit `index.html` to update your information
3. **Adjust Styling**: Modify `styles.css` to change colors, spacing, or typography
4. **Deploy**: Upload to any static hosting service (Netlify, Vercel, GitHub Pages)

## Customization Guide

### Update Your Information
- **Email**: Replace `hello@oliverwhite.com` with your actual email address
- **Projects**: Edit the three project cards in the "Featured work" section
- **About Section**: Personalize your background and expertise
- **Values**: Adjust the principles to reflect your own philosophy

### Color Scheme
The CSS uses CSS custom properties (variables) defined in `:root`. Key colors:
- `--accent`: Primary accent color (currently teal/mint)
- `--gold`: Secondary accent (currently warm yellow)
- `--rose`: Tertiary accent (currently pink/purple)

### Typography
- **Headings**: Playfair Display (serif, elegant)
- **Body**: Inter (sans-serif, modern and readable)
