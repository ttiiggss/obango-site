# Deployment Guide

Your website is ready to deploy! Here are the easiest methods:

## Option 1: Vercel (Recommended)

1. Go to [vercel.com](https://vercel.com)
2. Sign in with GitHub, GitLab, or Bitbucket
3. Click "Add New Project"
4. Import this folder or drag & drop the files
5. Vercel will auto-detect it as a static site
6. Click "Deploy"
7. Your site will be live at `https://your-project.vercel.app`

## Option 2: Netlify

1. Go to [netlify.com](https://netlify.com)
2. Sign in or create an account
3. Drag and drop the entire `personal-website` folder onto the Netlify dashboard
4. Your site will be live instantly at `https://random-name.netlify.app`
5. You can customize the domain in settings

## Option 3: GitHub Pages

1. Create a new GitHub repository
2. Push all files to the repository
3. Go to Settings → Pages
4. Select the main branch as source
5. Your site will be live at `https://yourusername.github.io/repository-name`
